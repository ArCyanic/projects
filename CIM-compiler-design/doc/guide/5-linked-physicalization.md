# 5　链接后物理化：从逻辑计算到部署程序

IREE 进入 HAL 阶段后，将同一目标的 executable 链接成一个部署单元。此前分散在不同目标函数中的静态权重和逻辑 MVM 汇集到同一个模块，后端由此获得全局阵列规划所需的完整输入。

链接后的物理化按数据依赖推进：

```text
linked logical CIM program
  → 重组可以合并执行的权重
  → 为全部常驻权重确定阵列坐标
  → 把边界和动态数据物化到 SRAM
  → 将逻辑 MVM 展开为位串行计算
  → 按完整生命周期分配 SRAM 地址
  → 序列化可执行程序
```

权重重组必须先于阵列放置，因为拼接和复制会改变矩形尺寸。阵列放置又必须先于位串行展开，因为每个物理计算轮次都要引用固定的权重坐标。SRAM 地址最后确定，使位串行展开新增的暂存能够进入同一生命周期分析。

物理化完成后，程序只剩部署期的权重写入和运行期的 bit、elt、copy。IREE 随后把它封装为 HAL executable binary，并继续完成主程序的 VM 下降。
