# 5.2　单阵列放置：确定常驻权重坐标

权重合法化和重组已经确定最终矩形，阵列规划器接下来为整个部署计算一份静态布局。输入是全部逻辑 MVM 引用的静态权重，输出是唯一阵列中的固定子区域，以及这些逻辑引用到物理区域的对应关系。

## 从权重视图得到矩形

逻辑权重可能来自完整全局数据，也可能是转置、切片或重组产生的静态视图。规划器按照视图的形状、偏移和步长读取实际 `[K,N]` 字节，形成连续的行主序矩形。

形状和字节内容都相同的矩形共享一个物理区域。若同一权重包含多个 N 切片，每次使用还保留切片对应的输出列偏移，使计算结果能够写回正确区间。

## 放置顺序

唯一矩形先按面积降序排列；面积相同时依次比较行数、列数和内容。较大的矩形先放置，减少小矩形提前占据关键空间的机会。

对每个矩形，按行号依次尝试第 0 行和所有已放置矩形的下边界。在每个候选行从第 0 列开始，按列扫描与候选区域在行方向相交的已有矩形，遇到阻挡就把候选列移到它的右边界。首个能容纳整个矩形的最左空位成为最终坐标：

\[
0\le row,\quad row+K\le1024,
\]

\[
0\le column,\quad column+N\le512,
\]

并且该区域与已有矩形不相交。固定的矩形排序和候选顺序使相同输入得到相同布局。 这种扫描能组合不同矩形提供的行边界与列边界；例如 `1024×512` 阵列中的 `512×256`、`768×128`、`256×384` 可依次放在 `(0,0)`、`(0,256)`、`(768,0)`。仅枚举已有矩形自身的右下角会漏掉第三块的合法位置。它仍是确定性的贪心放置，不保证找到所有可行布局。

## 从布局生成部署程序

规划结果创建一个 `1024 × 512` 的 i8 阵列根区域。每个唯一矩形对应根区域上的固定子视图，逻辑 MVM 的权重操作数改为该子视图。

布局同时生成部署入口 `__cim_array_init`。每个去重后的物理区域对应一条 `cim.array.load`，权重字节从 executable 内嵌数据写入固定阵列子视图。

部署入口与计算入口共享阵列根区域。部署完成后，所有计算都从固定子视图读取权重，矩形坐标也成为后续 `cim.bit` 的物理参数。

规划器处理的数学对象和完整约束见 [CIM Array Planning](../design/cim-array-planning.md)。
